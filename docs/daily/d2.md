# D2 入门合并与去噪

## 一句话理解
把两份不同来源的小数据（用户行为 + 工具结果）**合并、去重、统一时间、抹掉口水词**，输出 `merged.jsonl`。

## 输入文件
- `raw/d2/user_behavior.json` — 6 条用户行为记录（含重复、口水词、字段不统一、时间格式乱）
- `raw/d2/tool_result.json` — 3 条工具执行结果（含缓存标记、失败回执、错别字）

## 任务步骤
1. 编写 `merge_day2.py`，**逐行**处理两个文件
2. 统一字段名（`uid` / `user_id`、`time` / `timestamp`、`text` / `content`）
3. 统一时间为 ISO8601 格式，无法确认的标 `time_invalid=true`
4. 去重：完全相同记录合并；时间相近、文本相近的也要合并
5. 文本规整：去掉 `嗯…` `@@@` `!!!` `<!-- cached -->` 等噪声，但不改变原意
6. 工具结果保留 `status`、`latency_ms`、`output` 关键字段
7. 输出 `merged.jsonl`，每行一条 JSON，含 `source`、`uid`、`time`、`type`、`content` 五个字段

## 预期清理效果
- 同一用户的重复行为被合并（U001 那条会合并）
- 时间能排序，无法确认的时间被明确标记（U003）
- 工具结果中的状态、耗时、输出可直读
- 口水词、装饰符消失，意思不变

## 简单解释
> D2 是"洗菜"——两筐菜（用户行为、工具结果）都是脏的，洗干净按时间排好装一盘。
