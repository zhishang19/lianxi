# D1 观察 demo

## 一句话理解
看一眼脏数据长啥样，先别写代码，**只用眼睛和脑子**把"哪些能信、哪些要扔、哪些要复查"标出来。

## 为什么先做这一步
后面 5 天所有规则都从这里来。如果 D1 没看仔细，后面清洗会带偏见。

## 输入文件
- `raw/d1/observe_demo.txt` — 5 行样例，混合了用户指令、工具结果、纠错、隐私要求、知识片段
- `raw/d1/README.md` — 老师给的练习目标

## 任务步骤
1. 通读 5 行样例，给每行写 1 句话分类：**保留 / 删除 / 人工复查**
2. 标出每行里出现的"口水词"、"装饰符"、"缓存标记"、"隐私字段"
3. 写出 **5 条你自己的清洗假设**（每条一句话，能讲清为什么）
4. 提交一份 `report.md`，包含：
   - 你观察到的"临时指令 vs 长期偏好"差别
   - 你觉得必须脱敏的内容
   - 你标注的 `needs_review` 项

## 预期产出
- `report.md`（D1 不写脚本）

## 简单解释
> D1 是"看病人"——你还没动刀，先看 CT，决定哪里要切、哪里要观察。
